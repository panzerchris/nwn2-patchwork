## Defender delivery blocker

Defender event1116 at12:47:29 UTC reports
`Behavior:Win32/DefenseEvasion.A!ml`; event1117 at12:47:55 UTC confirms successful
quarantine of `nwn2-patchwork.exe`. Security intelligence1.463.21.0, engine1.1.26100.4.
This is a runtime behavior detection, not merely an unknown-publisher prompt.
The event does not identify the precise triggering API call.

The launcher intentionally uses a temporary child entry-point breakpoint, debugger
detach and remote DLL initialization so fixes are installed before game entry.
That supplies a plausible relationship to the behavior classification, not a
proved Microsoft false-positive determination. The behavior comes from our own
auditable launcher code; no third-party injection library or downloaded build
dependency is included. Do not try renamed/repacked copies, restore the quarantine,
change Defender settings or claim the download is cleared.
