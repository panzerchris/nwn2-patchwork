# 0.1.0 — Unpublished launcher candidate

Version 0.1.0 was not published. It was superseded by the drop-in DLL releases;
use a [published release](https://github.com/panzerchris/nwn2-patchwork/releases)
instead.

Microsoft Defender quarantined its separate launcher during testing. Microsoft
later closed the review after being unable to reproduce the detection. This
did not establish a correction to the original behavior detection, and the
candidate remains unpublished.

The original-build gameplay check was not completed. This candidate's testing
does not establish compatibility for a published release.
