## Gameplay testing

The published DLL was tested on Windows 11 with the supplied configuration and
both [supported GOG builds](../compatibility.md).

| Check | GOG 1.23 | GOG 1.23 v2 |
| --- | --- | --- |
| Startup and loading gameplay | Passed | Passed |
| Window width resizing and working controls afterward | Passed | Passed |
| Window movement and working controls afterward | Passed | Passed |
| Maximize and restore with recovered picture and controls | Passed | Passed |
| Applying a Graphics resolution | Earlier implementation testing only | Passed |
| Fullscreen entry and return with Alt+Enter | Earlier implementation testing only | Passed |

Minimize/focus recovery and optional borderless mode had passed earlier
implementation tests on both builds; they were not repeated on the release DLL.
Two restore checks required a retry after an automation capture error, so those
checks do not establish that the first input attempt worked.

Both game sessions closed without a hang. The original build returned an
unexplained nonzero exit code; no corresponding Windows application-crash report
was found. V2 returned zero.

The tested DLL produced no local Defender scan or gameplay detection.
That observation does not guarantee future antivirus results.

## Remaining gaps

Snap layouts, mixed-DPI and other monitor combinations, long sessions and
mod combinations have not been fully tested. Rendering can pause during
dragging, and the original HUD can stretch below 1024 pixels wide or 768 pixels high.

EPOS Connect can take focus after an exclusive-fullscreen resolution change.
Optional borderless mode provides a workaround.
This version does not include the faster multiplayer login added in 0.3.0.
