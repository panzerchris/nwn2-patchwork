## Gameplay testing

Testing used Windows 11 and the two [supported GOG builds](../compatibility.md).

- Both builds: faster login, repeated login/back navigation, multiplayer menus,
  Tutorial loading, movement controls and recovery after moving the game window.
- GOG v2: local dedicated-server joining, rejection of an incorrect password,
  disconnecting, LAN discovery and rejoining, gameplay controls, and normal
  timeout recovery for an unreachable server.

**These gameplay checks used an earlier build with the same runtime source.
The final 0.3.0 package was verified separately but was not retested in-game.**

For reproducibility, the tested runtime source was `41b518265d83cb5e3033246c479e9e9396f4b036`;
the tested DLL SHA-256 was
`fc34facce8a26838c7046b9ba8eca0434a66d63ad8fb215526d48b65836507d1`.

## Remaining gaps

Offline login, original-build server joining, hostname connections, multiple
players, hosting from inside the game and wider network/mod combinations have
not been tested. The public server browser and account service are not restored.

The display implementation is unchanged from
[0.2.0](v0.2.0-validation.md), with the same display limitations.
