## Runtime evidence

The multiplayer runtime source is identical to tested source
`41b518265d83cb5e3033246c479e9e9396f4b036`. Runtime validation used the earlier
branch CI DLL `fc34facce8a26838c7046b9ba8eca0434a66d63ad8fb215526d48b65836507d1`;
the table above identifies the separately verified 0.3.0 release artifact.

- Both supported builds: prompt native unavailable-service continuation, usable
  multiplayer menus, Tutorial loading, movement input and native title-move recovery.
- Both builds also have enabled repeat/back and feature-disabled natural-timeout
  comparisons. Observed disabled completion is about 31 seconds on the test PC;
  enabled warning captures are within two seconds including tool overhead.
- V2: actual local dedicated-server joining, native wrong-password rejection,
  normal disconnect, LAN discovery/rejoin and movement input. A controlled
  unreachable endpoint retains its separate native server timeout and recovery.

See [multiplayer evidence](../multiplayer.md) for the implementation boundary and
the earlier artifact identities. No game executable or assets are distributed.
Test sessions preserve settings, saves and existing character files.

## Scope

Isolated offline login, actual original-build server joining, hostname connection,
multiple players, integrated client hosting and wider network/mod combinations
are untested. The public browser/authentication service is not restored. Display
scope remains the existing [0.2.0 validation](v0.2.0-validation.md).

change or rebuild the recorded ZIP/DLL.
