# NWN2 Patchwork 0.2.0

**The first public release of Patchwork improves NWN2's window and fullscreen
recovery.** It includes fixes for moving and resizing the window, maximize/restore,
minimize/restore, resolution changes and Alt+Enter, plus optional borderless fullscreen.

Download **nwn2-patchwork-0.2.0-windows-x86.zip** below. Use x86 on 64-bit Windows too.

1. Close NWN2.
2. Extract `dinput8.dll` and the `nwn2-patchwork` folder beside `nwn2main.exe`.
   Do not overwrite another mod's `dinput8.dll`.
3. Start the game through your usual shortcut.

Edit `nwn2-patchwork/nwn2-patchwork.ini` with the game closed to change settings.
For borderless fullscreen, set `BorderlessAltEnter=1`, start windowed and press
Alt+Enter. To uninstall, close the game and remove Patchwork's `dinput8.dll`
and its `nwn2-patchwork` folder.

Supports the [documented GOG 1.23 and 1.23 v2 builds](https://github.com/panzerchris/nwn2-patchwork/blob/main/docs/compatibility.md),
not Enhanced Edition. Rendering may pause during dragging and should recover
when you release the window. The original HUD can stretch below 1024 by 768.
Other runtime patchers are not currently supported alongside Patchwork.

This is a prerelease. The published DLL was checked in-game on both supported
builds; monitor setups, long sessions and mod combinations have limited coverage.
See [testing and checksums](https://github.com/panzerchris/nwn2-patchwork/blob/main/docs/releases/v0.2.0-validation.md)
for details.

For faster multiplayer login as well as these display fixes, use
[0.3.0](https://github.com/panzerchris/nwn2-patchwork/releases/tag/v0.3.0).
